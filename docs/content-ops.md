# Content Operations

## Editing flow
1. Open `/admin`.
2. Authenticate via GitHub OAuth.
3. Update entries for settings/home/track-info/contact/pricing/schedule/sponsors/gallery.
4. Save draft and publish.
5. Validate production output after Amplify deploy completes.

## Content standards
- Every image requires descriptive alt text.
- Keep hero and CTA content concise.
- Do not remove required operational fields (practice/membership toggles).
- Keep schedule dates in `YYYY-MM-DD` format.
- Sponsors and gallery entries must include valid image path and alt text.

## Publishing checklist
- Validate home hero content and CTA destination.
- Validate schedule entries and cancellation state.
- Validate open/closed toggles for practice and membership.
- Validate sponsor visibility and gallery image rendering.
